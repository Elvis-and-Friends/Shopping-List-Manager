# Shopping List Manager

A collaborative Python project that demonstrates file handling operations using different file modes.

## Members and Contributions

| Student | File | Mode | Task |
|---------|------|------|------|
| Student A (Elvis) | elvis shopping.py | x and w | Create and initialize the file |
| Student B (Viss) | viss shopping.py | a | Append new items to the list |
| Student C | read.py | r | Read the file and count lines |
| Student D | update.py | r+ | Update existing content |
| All Members | search_delete.py | r and w | Search and delete items |

## How to Run

1. `python "elvis shopping.py"` - run first to create the file
2. `python "viss shopping.py"` - adds more items
3. `python read.py` - reads and counts all lines
4. `python update.py` - updates an item
5. `python search_delete.py` - search or delete an item

## Project Info

- Language: Python
- File Storage: shopping_list.txt
- Concepts: File handling (x, w, a, r, r+), try-except error handling
